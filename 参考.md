基于你提供的 `chrome-extension-boilerplate-react-vite` 模板，实现**视频自动续播**、**倍速控制**和**全局设置管理**。

以下是完整的开发指南：

---

### 第一步：环境准备与项目初始化

按照文档指引搭建基础框架：

1.  **克隆模板**：
    ```bash
    git clone https://github.com/Jonghakseo/chrome-extension-boilerplate-react-vite.git video-helper-extension
    cd video-helper-extension
    ```
2.  **安装依赖**：
    ```bash
    npm install
    ```

---

### 第二步：配置 `manifest.json`

我们需要权限来注入脚本、访问存储和所有网页。修改 `public/manifest.json`：

```json
{
  "manifest_version": 3,
  "name": "视频助手 - 自动续播&倍速",
  "version": "1.0.0",
  "description": "检测视频暂停自动播放，支持全局倍速控制",
  "background": {
    "service_worker": "src/pages/background/index.ts",
    "type": "module"
  },
  "action": {
    "default_popup": "src/pages/popup/index.html",
    "default_icon": "assets/icon-34.png"
  },
  "icons": {
    "128": "assets/icon-128.png"
  },
  "content_scripts": [
    {
      "matches": ["<all_urls>"],
      "js": ["src/pages/content/index.ts"],
      "all_frames": true
    }
  ],
  "permissions": ["storage"]
}
```
*注：`"all_frames": true` 是为了处理嵌套在 iframe 中的视频。*

### 第三步：核心功能开发

#### 1. 内容脚本 (`src/pages/content/index.ts`)
这是插件的核心，负责检测页面视频、监听暂停和控制倍速。

```typescript
// 定义设置类型
interface ExtensionSettings {
  autoResume: boolean;
  speed: number;
}

// 默认设置
const defaultSettings: ExtensionSettings = {
  autoResume: true,
  speed: 1
};

// 当前设置缓存
let currentSettings: ExtensionSettings = defaultSettings;

// 处理单个视频元素
const processVideo = (video: HTMLVideoElement) => {
  // 1. 设置倍速
  video.playbackRate = currentSettings.speed;

  // 2. 防止暂停（如果开启了自动续播）
  if (currentSettings.autoResume) {
    video.onpause = () => {
      // 稍微延迟一下，避免是用户手动切换视频时的抖动
      setTimeout(() => {
        video.play().catch(() => { /* 忽略自动播放被浏览器拦截的错误 */ });
      }, 100);
    };
  } else {
    video.onpause = null;
  }
};

// 扫描页面所有视频
const scanAndProcessVideos = () => {
  document.querySelectorAll('video').forEach(processVideo);
};

// 监听设置变化
chrome.storage.local.get(defaultSettings, (data) => {
  currentSettings = data as ExtensionSettings;
  scanAndProcessVideos();
});

chrome.storage.onChanged.addListener((changes) => {
  if (changes.autoResume || changes.speed) {
    currentSettings = {
      ...currentSettings,
      ...(changes.autoResume && { autoResume: changes.autoResume.newValue }),
      ...(changes.speed && { speed: changes.speed.newValue })
    };
    scanAndProcessVideos();
  }
});

// 使用 MutationObserver 监听动态加载的视频
const observer = new MutationObserver(() => {
  scanAndProcessVideos();
});

observer.observe(document.body, {
  childList: true,
  subtree: true
});
```

#### 2. 弹出页界面 (`src/pages/popup/Popup.tsx`)
用于给用户提供控制面板。

```typescript
import React, { useEffect, useState } from 'react';

const Popup = () => {
  const [autoResume, setAutoResume] = useState(true);
  const [speed, setSpeed] = useState(1);

  // 初始化加载设置
  useEffect(() => {
    chrome.storage.local.get(['autoResume', 'speed'], (result) => {
      if (result.autoResume !== undefined) setAutoResume(result.autoResume);
      if (result.speed !== undefined) setSpeed(result.speed);
    });
  }, []);

  // 保存设置
  const saveSettings = (newSettings: { autoResume?: boolean; speed?: number }) => {
    chrome.storage.local.set(newSettings);
  };

  return (
    <div style={{ width: 240, padding: 16 }}>
      <h3 style={{ margin: '0 0 16px 0' }}>视频助手设置</h3>
      
      <div style={{ marginBottom: 16 }}>
        <label style={{ display: 'flex', alignItems: 'center', cursor: 'pointer' }}>
          <input
            type="checkbox"
            checked={autoResume}
            onChange={(e) => {
              setAutoResume(e.target.checked);
              saveSettings({ autoResume: e.target.checked });
            }}
            style={{ marginRight: 8 }}
          />
          暂停时自动续播
        </label>
      </div>

      <div>
        <label style={{ display: 'block', marginBottom: 8 }}>播放速度:</label>
        <div style={{ display: 'flex', gap: 8 }}>
          {[0.5, 1, 1.5, 2, 3].map((s) => (
            <button
              key={s}
              onClick={() => {
                setSpeed(s);
                saveSettings({ speed: s });
              }}
              style={{
                flex: 1,
                padding: '4px 8px',
                border: speed === s ? '2px solid blue' : '1px solid #ccc',
                background: speed === s ? '#eef' : '#fff',
                cursor: 'pointer'
              }}
            >
              {s}x
            </button>
          ))}
        </div>
      </div>
    </div>
  );
};

export default Popup;
```

### 第四步：运行与调试

1.  **启动开发模式**：
    ```bash
    npm run dev
    ```
2.  **加载插件**：
    *   打开 Chrome 访问 `chrome://extensions/`。
    *   开启右上角“开发者模式”。
    *   点击“加载已解压的扩展程序”，选择项目根目录下的 `dist` 文件夹。
3.  **测试**：
    *   打开任意有视频的网页（如 Bilibili 或 YouTube）。
    *   点击视频暂停，观察是否自动续播。
    *   点击插件图标修改倍速，观察视频是否立即变速。

### 进阶优化建议（可选）

*   **白名单机制**：在 Popup 增加“启用/禁用当前网站”的功能，避免在网课等不需要的网站干扰。
*   **智能检测**：检测是用户手动点击暂停还是视频播完暂停，或者检测广告。
*   **快捷键**：在 `manifest` 中添加 `commands` 配置，支持用键盘快捷键切换倍速。
